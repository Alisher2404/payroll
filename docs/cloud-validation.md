Основные команды:

```text
uv venv --python 3.13 .venv-cloud
uv pip install --python .venv-cloud/Scripts/python.exe -r requirements.txt
uv pip check --python .venv-cloud/Scripts/python.exe
.venv-cloud/Scripts/python.exe run_checks.py
.venv-cloud/Scripts/python.exe qa/cloud_health.py
uv pip compile requirements.txt --python-version 3.13 --python-platform x86_64-unknown-linux-gnu --only-binary :all: --output-file qa/requirements-linux313.txt
```

Вспомогательные файлы qa не публикуются. Первоначальная параллельная повторная установка uv ожидала блокировку незавершённой загрузки PyArrow и завершилась таймаутом; основной чистый install завершился успешно. Повторная установка окончательного requirements.txt, проверка совместимости и тесты выполнены уже после завершения загрузки.

Проверены в том числе все разделы через Streamlit AppTest, расчёты/выплаты, роли, архив, удаления с резервированием, версии записей, Excel/PDF, начальная облачная настройка через Secrets, отказ без Secrets, вход бухгалтера, одновременные первые посетители, завершение прерванной загрузки демо, отсутствие повторного заполнения после удаления, восстановление демо после потери файла SQLite, хеширование паролей и переход даты по Душанбе при UTC 20:30.

## Что пока не выполнено

**Реальный запуск в Linux/Python 3.13 ещё не выполнен.** Компьютер работает под Windows; Docker не обнаружен, WSL не установлен. Подбор Linux-пакетов не является запуском тестов в Linux.

Добавлен `.github/workflows/cloud-check.yml`: на Ubuntu + Python 3.13 он устанавливает зависимости в чистой среде, выполняет pip check, весь pytest и реальный HTTP health-check Streamlit. Он запустится при первом push в main. Фактическое подтверждение — зелёный запуск Cloud check → linux-python313 в GitHub Actions. Репозиторий и приложение от имени пользователя в этой задаче не публиковались: пользователь запросил подготовку и инструкцию.

Сохранность SQLite в Community Cloud не гарантируется. После потери файла создаётся новая демонстрационная база; потерянные изменения не восстанавливаются. Проверка не подтверждает пригодность бесплатного временного диска для реального зарплатного учёта.
